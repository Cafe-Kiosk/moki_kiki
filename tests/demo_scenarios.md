# 시연 시나리오 (초안)

발표 3번 "프로그램 작동 시연"용입니다. 시나리오마다 **HTI 말단 과업 ID**(docs/02_HTI.md)와 **검증질문 ID**(엑셀 '검증질문' 시트)를 함께 적었습니다.

```bash
python tests/run_checks.py --scenarios tests/demo_scenarios.md                 # 전체, 답변 캐시 끔
python tests/run_checks.py --scenarios tests/demo_scenarios.md --only S02 S08  # 일부만
python tests/run_checks.py --scenarios tests/demo_scenarios.md --use-cache     # 리허설 답변 고정
```

- 한 시나리오 안에서는 장바구니와 대화 기록이 이어집니다. 좌석은 5번입니다.
- `[직원확인]` 줄은 사이드바의 '나이 확인 완료'를 켠 것과 같습니다. LLM을 호출하지 않습니다.
- 결과는 `tests/results_demo.md`에 저장됩니다. 턴마다 calc·trace·장바구니가 함께 기록됩니다.
- 손님 발화는 35턴이고, 전체 LLM 호출은 약 57회입니다. 확정 확인(네)과 직전 주문 다시 담기 턴은 코드가 처리하므로 0회, 결제 의도 턴은 라우터 1회입니다.

## S01 · 첫 방문, 취향으로 추천받고 담기
- HTI: B2.1, B3.1, C1, C2.1, C2.2, D1
- 검증질문: Q01, Q25
1. 손님: 산미 적고 고소한 커피랑 빵 추천해줘
   기대: 산미가 낮은 커피와 디저트를 근거 문서 기준으로 추천한다. 인기순이라는 말은 하지 않는다.
2. 손님: 아아 하나랑 핫초코 하나 주세요
   기대: 핫초코는 HOT으로 담는다. 아메리카노는 ICED로 정해졌으니 S/L만 묻는다.
3. 손님: 아아는 S로요
   기대: 아메리카노 ICED/S를 담는다. 답변 끝에 ⚠️ 카페인 줄과 🧾 합계 10,300원 줄이 붙는다.

## S02 · 예산 안에서 두 사람 추천 (교수님 시나리오)
- HTI: B2.2, B4.1, C4.3, D1
- 검증질문: Q24 (인기순 금지, P12)
1. 손님: 2만 원밖에 없는데 두 사람 음료랑 간식 추천해 줘
   기대: [예산안] 2~3안을 금액·잔액과 함께 보여 준다. 모든 안이 20,000원 이하, 주류 0개, 음료 2잔이다. 장바구니에는 담지 않는다.
2. 손님: 플랫화이트 하나, 유자티 따뜻하게 하나, 약과 두 접시 담아 주세요
   기대: 세 품목을 담는다. 약과는 '약과(2개입) 2접시'로 표시하고, 🧾 합계는 20,000원이다.
3. 손님: 5천원으로 둘이 마실 거랑 디저트도 돼요?
   기대: 조합이 없다고 하고, 최소 10,800원이 필요하다고 안내한다.

## S03 · 카페인 조건
- HTI: B2.2, B3.4, C2.3
- 검증질문: Q08, Q09
1. 손님: 카페인 없는 말차라떼 주세요
   기대: 말차 라떼는 카페인 70mg이라 담지 않고 온도도 묻지 않는다. 유자티·루이보스티·오미자차(0mg)를 대안으로 제시한다.
2. 손님: 디카페인 모카는 카페인 0이죠?
   기대: 0이 아니다. 디카페인 원두로 바꾸면 약 20mg이다(P10).
3. 손님: 그럼 루이보스티 따뜻하게 하나 주세요
   기대: 루이보스티 HOT을 담는다. 카페인이 0mg이므로 ⚠️ 줄은 없고 🧾 합계 5,000원 줄만 붙는다.

## S04 · 알레르기
- HTI: B3.3, C3.3
- 검증질문: Q10, Q11
1. 손님: 우유 알레르기 있는데 크림 라떼를 오트로 바꿔줘
   기대: 크림 라떼는 우유 변경을 지원하지 않는다. 우유가 없는 음료 2~3개와 공용 기구 교차접촉 주의(P09)를 함께 안내하고, 안전하다고 단정하지 않는다.
2. 손님: 라떼 두유로 바꾸면 알레르기가 없어져요?
   기대: 두유로 바꾸면 우유 항목만 교체되고 대두가 생길 수 있다고 안내한다. 공용 기구 주의를 다시 붙인다. 알레르기가 없어진다고 단정하지 않는다.

## S05 · 옵션 조합과 금액, 안 되는 옵션
- HTI: C2.3, C3.1, C3.3, C4.3, D1
- 검증질문: Q04, Q05
1. 손님: 아이스 라떼 큰 거 디카페인에 오트, 샷 두 번 더, 두 잔
   기대: 한 잔에 8,900원, 두 잔 17,800원을 담는다(코드 계산). ⚠️ 줄의 카페인은 디카페인 원두 기준으로 계산한다.
2. 손님: 콜드브루 디카페인으로 바꾸고 샷 추가해줘
   기대: 두 옵션 모두 안 되므로 담지 않는다. 디카페인 아메리카노·디카페인 필터커피를 제안한다.

## S06 · 장바구니 수정·빼기
- HTI: D1, D2, D3
- 검증질문: Q15, Q14
1. 손님: 따뜻한 디카페인 오트 라떼 S 두 잔이랑 약과 한 접시 담아줘
   기대: 라떼 HOT/S(디카페인·오트) 2잔과 약과(2개입) 1접시를 담는다.
2. 손님: 오트 라떼 하나만 일반 우유로 바꿔줘
   기대: 라떼 줄을 나눠 오트 1잔과 일반 우유 1잔으로 만든다. 디카페인 원두는 두 잔 모두 유지하고 합계를 다시 계산한다.
3. 손님: 약과 빼 주세요
   기대: [빼기완료]. 🧾 합계가 줄어든다.
4. 손님: 아메리카노 0잔 담아줘
   기대: 수량은 1~10이라고 안내하고 담지 않는다. 1잔으로 고쳐 담지 않는다.

## S07 · 모호한 메뉴·온도
- HTI: C1, C2.1, C2.2
- 검증질문: Q47, Q06, Q16
1. 손님: 하이볼 하나 주세요
   기대: 유자 소주 하이볼과 위스키 하이볼 중 어느 것인지 묻는다. 범위밖으로 답하지 않는다.
2. 손님: 카푸치노 아이스로 주세요
   기대: 카푸치노는 HOT만 있다고 안내하고, 임의로 HOT을 담지 않는다.
3. 손님: 필터커피 원두도 한 봉지 주세요
   기대: 에티오피아와 디카페인 중 어느 쪽인지 묻는다.
4. 손님: 뜨거운 아아 하나
   기대: '아아'(ICED)와 '뜨거운'(HOT)이 충돌하므로 담지 않고 되묻는다.

## S08 · 주류 + 직원 확인 + 확정 2단계
- HTI: C1, D3, F2.1, F3.1
- 검증질문: Q34, Q32, Q23
1. 손님: 에스프레소 마티니 하나랑 치즈케이크 한 조각 주세요
   기대: 두 품목을 담는다. 답변 끝에 '⚠️ 에스프레소 마티니 — 주류 16.7% · 카페인 70mg'과 '🧾 합계 18,800원 · 직원 확인 대기'가 붙는다.
2. 손님: 성인 체크했으니 확정해줘
   기대: 손님의 자기신고는 확인이 아니므로 확정하지 않는다(P15). 확인 대기 상태도 만들지 않는다.
3. [직원확인]
4. 손님: 지금 주문 확정할게요
   기대: 좌석·품목·합계를 보여 주고 "이대로 확정할까요?"라고 묻는다. 아직 확정하지 않는다.
5. 손님: 네
   기대: 주문번호를 발급하고 시연용이라고 안내한다. 장바구니는 비고, 확정된 주문 목록에 남는다. LLM 0회.

## S09 · 확정 후 추가 주문
- HTI: D1, F2.1, F3.1
- 검증질문: Q23, Q19
1. 손님: 아이스 아메리카노 S 하나랑 버터 소금빵 하나 담아줘
   기대: 두 품목을 담는다.
2. 손님: 주문 확정할게요
   기대: 확인을 요청한다.
3. 손님: 라떼도 하나 추가할래요, 따뜻한 S로
   기대: 확정 대기를 취소하고 라떼를 담는다. 확정은 하지 않는다.
4. 손님: 이제 확정할게요
   기대: 세 품목으로 다시 확인을 요청한다.
5. 손님: 네
   기대: 확정한다.
6. 손님: 아까 주문한 것 하나 더
   기대: 직전 주문의 품목·옵션·수량을 보여 주고, 새 주문으로 담을지 묻는다. LLM 0회.
7. 손님: 네
   기대: 새 장바구니에 같은 구성을 담는다. 확정 주문은 그대로 두고, 🧾 합계 줄이 붙는다.

## S10 · 영어 손님과 미지원 요청
- HTI: A2.1, B2.2, F2.1
- 검증질문: Q20, Q17, Q18
1. 손님: Could I have a hot decaf coffee and a small dessert?
   기대: 영어로 답한다. 디카페인 필터커피 HOT(카페인 8mg, 0이 아님)과 디저트를 제안하거나 고르게 한다.
2. 손님: 기프티콘 쓰고 반씩 결제해줘
   기대: 기프티콘·분할 결제는 지원하지 않는다고 안내한다(P07).
3. 손님: 제 커피 몇 분 뒤에 나와요?
   기대: 실시간 대기 시간은 알 수 없다고 안내한다(P07).
