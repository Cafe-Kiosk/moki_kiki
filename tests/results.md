## 67개 질문의 판정

**핵심 기준 확인 57 / 확인 질문·재선택 8 / 원안과 제안 차이 2.** 이를 원안의 모든 문구가 일치한 67개 통과로 표현하지 않는다.

- 핵심 기준 확인에는 정상 주문뿐 아니라 올바른 거절·미지원 안내·상태 보존이 포함된다. `handled=false`는 올바르게 막은 요청일 수도 있으므로 합격률로 사용하지 않는다.
- 확인 질문·재선택: Q03·Q07·Q25·Q31·Q33·Q39·Q47·R04. 크기/판매 단위/메뉴가 모호하거나 제공 불가하여 장바구니를 바꾸지 않았다. Q03의 후속 크기 응답은 연속 대화에서 완료했다.
- 제안 차이: Q01은 원안의 아메리카노 대신 산미 낮은 라떼류/콜드브루와 소금빵, Q20은 약과 대신 티라미수를 제안했다. 둘 다 판매 자료에 있는 후보이며 자동 주문하지 않았다. 특정 추천 메뉴를 고정해야 한다면 팀 시험 기준에 맞춰 추가 조정한다.
- 원안에는 정보·대안 예시도 있다. 실제 답변이 예시의 모든 문구를 재현하는지는 별도 문제다. 예를 들어 Q34는 정확한 금액과 직원 확인 대기를 표시하며, 마티니 성분·카페인은 별도 정보 문의로 확인할 수 있다.

[질문별 판정 CSV](reviewed_results.csv) · [원문·계획·전후 상태·근거·판정을 합친 JSON](reviewed_results.json).
최신 증거 파일을 명시했다. 이전 실패나 수정 전 실행도 삭제하지 않았다. 일부 질문은 이전 검사 시점의 결과를 사용하며 마지막 코드에서 67개를 모두 다시 실행한 것은 아니다. 변경 영향 범위는 회귀 시험과 해당 질문 재실행으로 확인했다.

## 실제 연속 대화

1. 따뜻한 디카페인 라떼+약과 → 크기 질문 → 작은 크기 → **10,700원**.
2. 라떼만 하나 더 → 디카페인 유지, **16,900원**.
3. 내역 보기 → 시연 확정 → 추가 아메리카노 **4,500원**. 이전 16,900원 주문과 번호 보존.
4. 영어 전환 → 주문 조회 → 전체 취소 질문 → 수락 → 현재 장바구니 0원. 과거 주문 보존.
5. 다른 대화: 우유 회피·카페인 30mg 이하 → 오트 디카페인 라떼 **6,700원**, 조건 유지.
6. 다른 대화: 라떼 **5,500원** → 직전 변경 되돌리기 → 0원.

`run_conversations.py`는 금액·확정 상태·과거 번호·옵션·회피 조건을 assert로 확인한다. 라우터와 응답은 실제 API이며, 같은 라우팅을 중복 호출하지 않도록 시험 시 한 번 얻은 결과만 실행에 전달한다.

## 재현

```bash
python scripts/validate_data.py
python -m unittest discover -s tests -p test_regressions.py -v
python tests/test_logic.py
python tests/review_results.py
# OPENAI_API_KEY 설정 후: 유료 API 실행
python tests/run_checks.py --all --output tests/new_live_results.json
python tests/run_conversations.py
```

LLM 출력은 다음 실행에서 달라질 수 있다. 시험표는 전 조합·55개 HTI 과업의 완전한 검증이 아니다. 자동 업셀/페어링 수락 분기, 실제 음성 청취, 팀 사용성 평가는 남아 있다. 실제 결제·접수·제조·직원 인증은 이번 구현 범위에 없다.
