| | |
|---|---|

| **한 줄** | 소외되는 사람이 없는 모두의 키오스크 |
| **캐릭터** | 모키 — 귀가 큼. 모두의 소리를 경청한다는 의미 |

## 왜 계산대 키오스크가 아니라 좌석 태블릿인가

타자로 대화하며 주문하면 주문 시간이 길어진다. 계산대 앞 키오스크로는
뒷사람 대기 문제가 생긴다. 그래서 **앉아서 천천히 주문하는 방식**으로 고정했다.

이 결정이 데이터의 좌석 번호(1~12, 매장정책 P02)와 매장 이용 기본값(P04)으로 이어진다.

## 팀 간 약속

- **문서 종류**: 메뉴 / 옵션 규칙 / 매장·정책
- **코드 공유**: 이 저장소
