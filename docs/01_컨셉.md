# 모키 커피바: 컨셉과 구현 범위

모키는 **매장 테이블의 태블릿에서 글로 질문하고 주문을 구성하는 가상 커피바 키오스크**다.
외국어 메뉴 설명이나 성분·카페인 정보가 필요한 손님이 자신에게 맞는 선택을 이해하도록 돕는다.
한국어·영어를 지원하고, 알레르기·임신에 대한 안전 보장이나 진단은 하지 않는다.

## 사용 환경

- 좌석 1~12. 기본은 매장 이용, 비주류는 포장 선택 가능.
- 현실적인 규모의 가상 메뉴 v4: 33개 메뉴/52개 판매 구성/6개 옵션/19개 정책.
- 메뉴·설명·정책은 RAG 검색, 금액·옵션·수량·상태 변경은 코드 검증.
- 실제 결제와 매장 접수는 없다. 최종 내역 검토와 명시적 수락 뒤 시연 번호를 만든다.
- 확정 주문은 보존한다. 추가 주문은 같은 좌석의 새 장바구니로 시작한다.
- 주류 6종은 직원 확인 대기까지만 지원하며 고객의 체크나 발언으로 승인하지 않는다.
- 글자 크기·고대비·브라우저 읽어주기는 사용자가 화면에서 직접 선택한다.

## 설계 이유

테이블에서 대화하면 계산대 대기를 걱정하지 않고 메뉴를 비교할 수 있다는 팀 가설이다.
대기시간 단축이나 사용자 만족도 향상을 실측한 결과는 아니다.
귀가 큰 모키 캐릭터는 사용자의 조건을 경청한다는 의미를 담는다.

## 완료의 의미

컨셉·데이터·HTI·앱은 위 범위로 맞췄다. 상세 HTI 원문은 보존하고 미지원 과업은 제한 안내로 대응한다.
유료 API 실험·코드/화면 시험·외부 배포·팀 채택·과제 제출은 각각 별도 증거로 기록한다.
