# HTI 원문 기준과 시연 대응

근거: 2026-10-15 저장된 박채원 HTI 탭의 내용·취소선 서식 확인 기록. 이번 업로드 중 클라우드 원문은 새로 조회하지 않았습니다.

발표 11장은 현재 취소선 없는 A~F의 상위 목표와 대표 행동을 요약했다. 아래 원문 목록은 사용자 과업의 설계 범위다. 원문에 있는 모든 선택값과 결제 방식이 현재 프로토타입에 구현되었다는 뜻은 아니다. 원문의 G·H와 하위 항목은 취소선이므로 발표의 HTI 계층에서 제외했다.

## 시연과 과업의 연결

| 원문 과업 | 발표에서 보여줄 장면 |
|---|---|
| A1.2 좌석 번호 확인하기 | 좌석 5번 확인 후 시작 |
| B4.1 여러 메뉴의 맛·가격 비교하기 | 아메리카노와 카푸치노 비교 |
| C2.1 온도 정하기 · C2.2 사이즈 정하기 | 따뜻한 라떼 주문 뒤 작은 크기로 답하기 |
| C2.3 원두 정하기 | 디카페인 선택 조건을 유지해 주문하기 |
| C3.1 샷 추가하기 · C3.3 우유 바꾸기 | 10장의 오트·추가 샷 금액 사례 |
| D1.1 선택한 메뉴 담기 | 디카페인 라떼와 약과를 함께 담기 |
| D2.1 수량 바꾸기 | “라떼만 하나 더”로 두 잔 만들기 |
| D3.1 메뉴별 구성과 총액 확인하기 | 10,700원 → 16,900원 확인 |
| E1.1 매장 / 포장 선택하기 | 매장 이용 상태 확인 |
| F2.1 최종 주문 내역 확인하기 · F3.1 주문번호 확인하기 | 내역 검토 뒤 시연 주문 확정과 번호 확인 |

현재 프로토타입은 한국어·영어, 판매 자료의 S/L과 샷 추가 0~2를 사용한다. F 결제 과업은 가상 주문의 검토·확정·번호 발급으로 시연한다. 쿠폰·포인트·실제 금융 결제나 직원 인증을 실행했다고 설명하지 않는다.

확정 뒤 새 장바구니 추가, 언어 전환 중 상태 보존, 취소 확인은 앱에서 확인한 추가 동작으로 소개할 수 있다. 이 동작을 원문의 G·H 확정 과업으로 번호 매기지 않는다.
