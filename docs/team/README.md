# 모키 커피바 팀원용 통합 안내

정리 기준: **2026-10-15 KST**. 기존 파일·저장된 실행 결과·현재 GitHub·공식 제출 공지를 대조했습니다.
이 안내는 팀이 검토할 공통 기준이며 각 팀원의 실제 기여 전체, 최종 채택, 배포나 제출 완료를 증명하지 않습니다.

## 모든 팀원이 먼저 알아야 할 여덟 가지

1. 모키는 **테이블에서 글로 질문하고 주문하는 가상 커피바**입니다. 커피바 선택 이유는 충분히 비교·질문하고 추가 주문할 수 있는 사용 장면입니다. 대기 감소·매출 증가는 측정 성과가 아닌 설계 목표입니다.
2. 데이터 v4는 메뉴 **33개**, 판매 구성 **52개**, 옵션 **6개**, 정책 **19개**입니다. 앱 검색 문서 61개와 한영 전달 문서 122개는 구성 방식이 다릅니다.
3. 최신 발표 HTI는 **A~F**입니다. 저장된 10월 15일 원문 확인에서 G·H는 취소선입니다. 예전 개발 HTI의 A~H·55개 말단 과업과 섞지 않습니다.
4. HTI에 적힌 언어·크기·결제 선택을 모두 구현한 것은 아닙니다. 앱은 한영, 데이터에 있는 판매 구성, 추가 샷 0~2 등을 사용합니다. F 결제 과업은 **내역 검토 → 시연 확정 → 번호 확인**으로 보여줍니다.
5. 가격과 주문 상태의 최종 기준은 코드입니다. 추천만으로 담기, 임의 옵션 대체, 고객의 말로 직원 승인 처리, 확정 내역 덮어쓰기를 허용해서는 안 됩니다.
6. 발표가 설명하는 수정 후보는 **PR #1의 `bb5b0a2`**입니다. 조회 당시 OPEN/DRAFT/미병합이며 `main` 앱·팀 공유앱과 같은 버전이라고 확인되지 않았습니다.
7. 원안 질문 67개는 **57개 핵심 기준 확인·8개 확인/재선택·2개 제안 차이**로 검토했습니다. ‘67개 기대 문구 완전 일치’라고 말하지 않습니다. 최신 코드에서 67개를 한꺼번에 재실행한 기록도 아닙니다.
8. 제출물은 **발표 PDF + 실행 가능한 프로그램**, 기한은 **발표일 오전 9시**입니다. 팀 일정의 발표일은 10월 16일이므로 준비 목표는 **2026-10-16 09:00 KST**입니다. 실제 제출·접수는 별도 확인해야 합니다.

## 회의에서 확정할 일

- 시연에 `main`과 수정 후보 중 어느 버전을 사용할지, 해당 브랜치·커밋과 시연 컴퓨터를 확정합니다.
- 개발·프롬프트·데이터 담당이 현재 계약과 검증 결과를 함께 확인합니다. 이 문서의 담당 구분은 기존 회의 기록을 따르며 새 담당 배정을 뜻하지 않습니다.
- 실제 API가 가능한 환경에서 핵심 주문 흐름을 리허설하고, 팀 공유앱을 쓸 경우 그 배포 버전을 별도로 대조합니다.
- 발표·시연·제출 담당자와 전달 파일을 정하고 실제 제출 및 접수 증거를 확인합니다.
