2026-10-14 · 데이터 담당 제안 · 커피와 술을 함께 고르는 테이블 주문 커피바

## 1. 이번 수정의 기준

사용자 요청에 따라 간장버터 버섯구이와 김부각은 삭제한다. 한국 재료를 썼다는 이유로 별도 분류를 만들지 않는다. 주류는 더 늘려 커피바의 메뉴 선택지로 분명하게 자리 잡도록 한다.

외국인 접근성은 ‘한국 메뉴 코너’보다 이해하기 쉬운 이름·맛 설명·성분·판매 단위·주류 및 카페인 표시에서 확보한다. 한국 재료가 들어간 기존 차와 디저트는 일반 메뉴 안에서 자연스럽게 고르게 한다.

## 2. 주류는 2종에서 6종으로 확장

유자·오미자 칵테일만 있으면 술을 고르려는 손님에게 과일 계열 두 가지 선택지만 생긴다. 드라이한 하이볼, 커피 칵테일, 맥주, 잔 와인을 더해 선택의 차이를 분명히 한다.

| 역할 | 메뉴 | 시연 가격 | 도수 설정 | 제공 방식 |
|---|---|---:|---:|---|
| 감귤 풍미의 시그니처 | 유자 소주 하이볼 | 9,500원 | 약 5.3% | 얼음 포함 300ml 잔 |
| 새콤달콤한 시그니처 | 오미자 소주 스프리츠 | 10,000원 | 5.0% | 얼음 포함 300ml 잔 |
| 드라이한 기본 칵테일 | 위스키 하이볼 | 9,000원 | 10.0% | 얼음 포함 300ml 잔 |
| 커피와 주류를 연결 | 에스프레소 마티니 | 12,000원 | 약 16.7% | 차갑게, 얼음 없이 120ml |
| 익숙하고 간단한 선택 | 라거 맥주 | 7,000원 | 5.0% | 차갑게, 얼음 없이 330ml |
| 잔 단위 와인 선택 | 하우스 레드와인 | 9,000원 | 13.0% | 얼음 없이 150ml |

도수·가격·양은 실제 브랜드 상품 정보가 아닌 가상 매장 설정이다. 하이볼·스프리츠는 추가 얼음 희석 전, 마티니는 가정한 셰이킹 희석수 20ml를 포함해 계산했다. 카페인 70mg으로 설정한 마티니는 커피와 술을 모두 포함한다.

이번에는 새 안주나 식사 메뉴를 추가하지 않는다. 요청한 삭제를 반영하고, 기존 소금빵·치즈케이크·티라미수 등과 함께 고를 수 있는 규모로 정리한다. 음식 주문을 주류 주문의 필수 조건으로 만들지 않는다.

## 3. 분류는 5개로 통합

| 분류 | 메뉴 수 | 포함 범위 |
|---|---:|---|
| 커피 | 12 | 에스프레소·라떼·콜드브루·필터커피 |
| 차/논커피 | 7 | 말차·초코·밀크티·유자·루이보스·오미자·대추생강 |
| 디저트 | 5 | 소금빵·치즈케이크·티라미수·약과·쑥인절미 |
| 주류 | 6 | 칵테일 4종·맥주 1종·와인 1종 |
| 원두 | 3 | 하우스·에티오피아·디카페인 200g |
| 합계 | 33 | 메뉴마다 하나의 분류만 부여 |

‘한국의 맛’, ‘한국 차’, ‘한국 다과’ 같은 별도 탭이나 중복 그룹은 없다. ‘논커피’는 커피가 아닌 음료라는 뜻이며 무카페인과 같지 않다. 예를 들어 말차 라떼와 홍차 밀크티에는 카페인이 있다.

## 4. 데이터와 주문 규칙을 함께 수정

메뉴 삭제 → 주문 조합 삭제 → 사진·페어링·용어집 정리 → 분류 통합 → 새 주류와 한영 설명 추가 → 도수·영양 수식 수정 → RAG 재생성 → 엑셀·배포 파일 대조 순서로 반영한다.

‘하이볼 하나’는 유자 소주 하이볼인지 위스키 하이볼인지 확인한다. ‘차갑게’와 ‘얼음 포함’을 구별하고, 마티니·맥주에는 얼음을 넣지 않는 제공 방식을 명시한다. 주류 확인 규칙은 칵테일뿐 아니라 맥주와 와인에도 적용한다.

## 5. 참고와 창작의 경계

기존 커피·차·칵테일 참고처는 엑셀 **설계근거**와 JSON `references`에 남겼다. 새로 [IBA Espresso Martini](https://iba-world.com/iba-cocktail/espresso-martini/)의 재료 역할과 흔들어 거르는 제공 방식을 참고했다. 모키의 배합 비율·도수·영양·카페인·가격은 별도 가상 설정이다. 참고처의 실제 메뉴나 사진을 복제하지 않았다.

사진은 기존 29장을 유지하고 내장 `image_gen`으로 새 주류 4장을 생성했다. 아이보리 벽, 밝은 석재 테이블, 월넛 배경, 왼쪽 자연광을 공통으로 사용한다. 최종 사진과 생성 프롬프트는 배포 폴더에 함께 포함한다.
