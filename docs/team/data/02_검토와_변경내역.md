## 확인한 범위

18개 정적·수식 검증을 수행했다. 메뉴 33개, 주문 조합 52개, 주류 6종, 분류별 12/7/5/6/3개를 대조했다. 유지된 48개 주문 단위의 기존 가격·영양은 보존했다.

한영 필드, 페어링·사진·원두·용어집·대안 참조, 삭제 ID, 하이볼 복수 후보, 주류 자동 추가 방지, 수량·옵션 경계를 확인했다. 17,800원 기존 복합 주문과 18,800원·32,000원 신규 주문 합계도 확인했다.

모든 주류의 원액 합산·도수·에탄올·열량을 대조했다. 엑셀에서 마티니의 두 번째 원액과 희석 기준을 임시로 바꿔 계산 연동을 확인한 뒤 원래 값으로 복원했다. 행 순서를 바꿔도 사진 카드가 ID로 이름과 가격을 찾는지 확인했다.

메뉴별 한영 RAG 2개씩, 전체 122개 문서와 사진 33장 연결을 대조했다. 계산 수식 오류를 점검하고, 영향을 받은 표·사진 메뉴판을 렌더링해 확인했다. 저장된 XLSX를 별도로 다시 읽어 데이터·수식 캐시·표 10개·필터·고정 창·내장 이미지 33장을 확인했다. ZIP 안의 40개 파일은 CRC와 원본 파일별 SHA-256으로 대조했다. v3 배포본 38개 파일도 기존 해시와 일치했다.

## 실제 실행과의 경계

검증질문 47개는 팀 앱에서 실행할 **시험안**이며 47개 실제 대화 통과 결과가 아니다. 직원 확인은 데이터 계약과 오프라인 규칙 검증이며 신분 확인 시스템을 구현한 것은 아니다. 실시간 RAG, 실제 주문·결제, 외국인 사용자 평가, Microsoft Excel 앱에서의 직접 조작은 수행하지 않았다.

원본 및 이전 v3 배포본은 보존한다. v4는 로컬 팀 배포용 묶음이며 팀 채팅 발송·배포 적용·팀 합의를 완료했다는 뜻은 아니다. 레시피·도수·영양·가격·사진은 시연용 설정이다.
