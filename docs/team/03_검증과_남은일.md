## 재현 명령

수정 후보 폴더에서 실행합니다. main에는 아래 모든 파일이 존재하지 않습니다.

```bash
python scripts/validate_data.py
MOKI_MOCK=1 python tests/test_logic.py
# MOCK 회귀 실행: 현재 저장 인덱스 모드 시험 1개는 위 설명의 환경 불일치가 있음
MOKI_MOCK=1 python -m unittest discover -s tests -p test_regressions.py -v
# 해당 시험만 실제 저장 인덱스 검증 모드로 확인. API 호출 전 모델 불일치를 검사
MOKI_MOCK=0 OPENAI_API_KEY=unused-offline-tests PYTHONPATH=tests python -m unittest test_regressions.OrderTests.test_source_mutation_rejects_stale_index -v
```

다음은 실제 API 사용과 비용이 발생할 수 있습니다. 실행 가능 환경에서 필요한 범위만 수행하고 새 결과 파일로 남깁니다.

```bash
MOKI_MOCK=0 python tests/run_checks.py --ids Q03 Q04 R05
MOKI_MOCK=0 python tests/run_checks.py --all --output tests/new_live_results.json
MOKI_MOCK=0 python tests/run_conversations.py
```

시험 전 실제 키를 로그에 출력하지 않습니다. `tests/results.md`·`reviewed_results.csv`는 수정 후보의 기존 기록이고 원안 NOT_RUN 표는 계획 이력을 보존한 자료입니다.
실제 결제·매장 접수·직원 인증·실제 재고·쿠폰·포인트·영수증은 현재 미지원입니다. 단일 성공 기록을 운영 성능이나 사용자 만족 성과로 확대하지 않습니다.
