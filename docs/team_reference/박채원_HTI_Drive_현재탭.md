아래는 지정 탭에서 읽은 문장을 보존한 사본이다. 지원 여부와 데이터 충돌은 별도 대응표에서 다룬다.

```text
0. 커피바 좌석 태블릿으로 주문하기
A. 주문 시작하기
 A1. 대화 시작하기
  A1.1 주문 시작하기 [필수]
  A1.2 좌석 번호 확인하기 [필수] (태블릿 자동 연동 시 확인만)
 A2. 이용 환경 맞추기 [요청 시]
  A2.1 언어 바꾸기 (입력 언어 자동 감지 / 한·영·중·일)
  A2.2 화면 보기 편하게 바꾸기 (글자 크기, 고대비)
  A2.3 손쉬운 보기 기능 선택하기
B. 메뉴 탐색하기
 B1. 메뉴 찾기
  B1.1 카테고리로 둘러보기 (에스프레소·필터커피·논커피·디저트·원두)
  B1.2 메뉴 이름으로 묻기
 B2. 추천받기
  B2.1 취향으로 추천받기 (단맛·산미·고소함·바디감)
  B2.2 상황으로 추천받기 (첫 방문, 카페인 적게, 디저트와 함께)
  B2.3 시그니처·시즌 메뉴 소개받기 [제안]
 B3. 메뉴 정보 확인하기 -> 질문시 대답
  B3.1 기본 정보 확인하기 (설명·가격·맛 노트) ← 메뉴 언급 시 기본 제공
  B3.2 원두 상세 확인하기 (산지·가공·로스팅) [요청 시]
  B3.3 알레르기·성분 확인하기 (우유·견과·글루텐 등) [요청 시]
  B3.4 카페인·칼로리 확인하기 [요청 시]
 B4. 메뉴 비교하기
  B4.1 여러 메뉴의 맛·가격 비교하기
C. 메뉴 선택 및 옵션 정하기
 C1. 메뉴 고르기
 C2. 기본 옵션 정하기 [필수]
  C2.1 온도 정하기 (HOT / ICE)
  C2.2 사이즈 정하기 (S / L / XL)
  C2.3 원두 정하기 (하우스 / 싱글오리진) ← 커피 메뉴만
 C3. 맞춤 옵션 정하기 [요청 시]
  C3.1 샷 추가하기 (+1 / +2 / +3)
  C3.2 단맛 조절하기 (시럽 종류·양)
  C3.3 우유 바꾸기 (일반 / 저지방 / 오트 / 두유)
  C3.4 얼음 조절하기 (양, 종류)
 C4. 옵션 확인하기
  C4.1 디저트 페어링 제안 수락·거절하기
  C4.2 사이즈 업·샷 추가 제안 수락·거절하기
  C4.3 적용된 옵션과 추가금 확인하기
D. 장바구니 관리하기
 D1. 담기
  D1.1 선택한 메뉴 담기
  D1.2 다른 메뉴 이어서 고르기
 D2. 수정하기
  D2.1 수량 바꾸기
  D2.2 옵션 바꾸기
  D2.3 메뉴 빼기
 D3. 확인하기
  D3.1 메뉴별 구성과 총액 확인하기
E. 이용·수령 방식 정하기
 E1. 이용 방식 정하기 [필수]
  E1.1 매장 / 포장 선택하기
  E1.2 컵 정하기 (매장컵 / 개인컵 / 일회용컵) ← E1.1에 따라 선택지 달라짐
  E1.3 포장 용품 요청하기 (캐리어·빨대) [요청 시]
F. 결제하기
 F1. 할인·적립 적용하기
  F1.2 쿠폰·포인트 사용하기 (보유 시 한 번 안내)
  F1.3 할인 적용 금액 확인하기
  F1.4 포인트 적립하기
 F2. 결제 진행하기
  F2.1 최종 주문 내역 확인하기 [필수]
  F2.2 결제 수단 선택하기 (카드 / 간편결제 / 기프티콘)
  F2.3 결제 나누기 (메뉴별 / N분의 1) [요청 시]
  F2.4 결제 실패 시 다시 시도하기
 F3. 주문 완료 확인하기
  F3.1 주문번호 확인하기
  F3.2 영수증 받기 (종이 / 전자 / 받지 않음)
G. 주문 후 이용하기  ← 신규
 G1. 주문 상태 확인하기 ("제 음료 언제 나와요?")
 G2. 추가 주문하기
  G2.1 두 번째 잔·디저트 추가하기 → 기존 주문에 합산
  G2.2 이전 주문 다시 시키기
 G3. 원두 구매하기
  G3.1 마신 원두 구매 문의·주문하기
H. 도움 받기 및 주문 되돌리기
 H1. 직원 도움 요청하기
  H1.1 바리스타 호출하기
  H1.2 원두 상담 요청하기
 H2. 이용 정보 확인하기
  H2.1 키오스크로 할 수 있는 일 묻기
  H2.2 매장 정보 묻기 (와이파이·화장실·영업시간·콘센트)
 H3. 되돌리기·종료하기
  H3.1 직전 변경 취소하기
  H3.2 진행 중 주문 취소하기
  H3.3 처음부터 다시 주문하기
```
