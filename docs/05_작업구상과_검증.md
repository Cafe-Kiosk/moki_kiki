# 완료 작업 구상과 검증 기준

2026-10-14 · 원본을 보존한 별도 Git 브랜치에서 진행한다.

1. **컨셉과 기준 고정**: 테이블 텍스트 주문, 가상 메뉴 v4, 실제 결제 없음, 주류는 직원 확인 대기. 사용자가 지정한 Google Drive 「박채원 HTI」 A~H를 기준으로 원문·구현·시험 대응표를 맞춘다. 선택값은 사용자 최종 결정대로 데이터 v4를 유지한다.
2. **데이터 검증과 검색 일치**: 현재 엑셀의 ID/가격/옵션/한영/정책 무결성을 검사한다. 메뉴 ID 기준 문서 연결, 모든 필수 검색 근거 보존, 저장 인덱스의 데이터/문서 버전 확인. 평가 문서는 검색에서 제외한다.
3. **주문 규칙과 상태**: 공유 Cart 경계에서 메뉴·판매 구성·옵션·정수 수량 검증. 다중 변경은 전체 검증 후 반영. 수정/일부 잔 분리/삭제/초기화, 검토 후 확정, 확정 주문 보존과 추가 주문, 오류 재시도 상태 보존.
4. **프롬프트와 앱 연결**: 기존 통합 라우터를 유지하며 복합 action과 실제 상태를 연결한다. 프롬프트팀 시스템 규칙을 적용하고 JSON/도구 상태를 검증한다. 가격·수정 결과는 코드가 표시한다. 고객 화면의 직원 인증 토글을 제거한다.
5. **검증과 재검토**: 금액/옵션/오류/확정에 단위·통합 시험, 저장 FAISS 검색, Streamlit 화면, 실제 LLM 대화를 순서대로 확인한다. 67개 시험안의 사전 상태와 결과를 구분해 기록한다. 실패는 원인 수정 후 재시험한다.
6. **전달**: 실행 안내·컨셉·HTI 대응·검증 기록·변경 요약·독립 실행 ZIP을 만든다. 원격 반영은 검토 가능한 PR로 준비한다. 운영 배포와 과제 제출은 별도 상태다.

영향 범위: src/cart.py와 모든 호출부(src/kiosk.py, app.py, tests), src/router.py/prompts, src/chain.py, src/documents.py/src/retrieve.py/src/index.py, scripts/build_index.py/tests/run_checks.py, README·docs·실행 설정·제출 패키지.
보존: 기존 데이터/팀 원문·이전 결과·확정 주문 기록. 비밀값은 커밋/ZIP/검증 로그에 넣지 않는다.
이번에 넓히지 않는 범위: 실결제·실시간 재고·예약·회원 서비스·음성 입력·실매장 직원 인증 서버.


## 실행 후 재검토

위 순서대로 1~5단계를 수행하고 6단계 전달 자료를 완성했다. 실제 대화에서 나온 수량·옵션·조건 답변·취소 수락 문제를 공통 처리부에서 고친 뒤 해당 사례와 오프라인 회귀 시험을 반복했다.
결과와 변경 원인은 [변경과 검증 결과](06_변경과_검증결과.md), 원본/재시험/의미 판정은 [시험 기록](../tests/results.md)에 연결했다. 20개 발표 요약은 [핵심 과업과 시연](07_발표용_핵심과업과_시연.md)으로 정리했다.
