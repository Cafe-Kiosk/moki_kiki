# HTI 기준과 구현 대응

기준은 [Google Drive의 「박채원 HTI」 탭](https://docs.google.com/document/d/1yXr5JnujZNLwXRJLVSZv33qNJENaGX8wB-XDYLmaB0U/edit?tab=t.7ipifvmjspo8)이다. 탭 ID와 제목을 연결 도구로 확인하고 현재 내용을 읽었다.

- A~H 구조와 원문 번호를 유지한다.
- 원문 사본: [박채원 HTI 현재 탭](team_reference/박채원_HTI_Drive_현재탭.md).
- 과업의 주어는 사용자다. 내부 검색·분류·API 단계는 HTI 과업으로 바꾸지 않는다.
- 사용자는 메뉴를 바로 주문하거나 정보만 묻고 끝낼 수 있다. 계층을 필수 수행 순서로 해석하지 않는다.
- 실제 선택값은 데이터 v4를 적용한다. 사용자가 확장안을 철회하고 기존 추천안을 선택한 범위다.
- 이전 131개 안은 현재 구현·시험의 기준이 아니다. 원래 작업 폴더의 참고 자료로 보존했다.

## A~H와 현재 동작

| 원문 범주 | 구현과 연결 | 제한 |
|---|---|---|
| A. 주문 시작하기 | 좌석 확인, 한·영 전환, 글자 크기·고대비·읽어주기 | 중·일은 미지원. 채팅이 화면 버튼을 대신 누르지 않음 |
| B. 메뉴 탐색하기 | 분류별 둘러보기, 메뉴 정보·추천·비교·성분·카페인 | 가상 메뉴 값이며 건강상 안전 보장·인기 순위 추정 없음 |
| C. 메뉴 선택 및 옵션 정하기 | 가능한 판매 구성·원두·샷·우유·단맛·얼음 검증 | XL·샷 +3·새 시럽·얼음 종류 변경 미지원 |
| D. 장바구니 관리하기 | 담기, 여러 품목, 수량·옵션 수정, 한 잔 분리, 삭제·총액 | 대상이 모호하면 확인, 전체 검증 전 부분 반영 없음 |
| E. 이용·수령 방식 정하기 | 매장/포장 선택, 주류 포장 차단 | 개인컵·캐리어·빨대 요청 실행은 미지원 안내 |
| F. 결제하기 | 최종 내역 확인 후 시연 확정·번호 | 쿠폰·포인트·할인·실제 결제·분할·영수증 미지원 |
| G. 주문 후 이용하기 | 시연 상태, 추가 주문, 이전 주문 다시 담기, 원두 구매 | 제조·대기시간 미연동. 확정 뒤 추가 주문은 새 주문 |
| H. 도움 받기 및 주문 되돌리기 | 한계·직접 문의 경로, 직전 변경 되돌리기, 취소 확인·새 주문 | 실제 직원 호출·확정 주문 취소는 미지원 |

## 원문과 데이터가 다른 부분

원문의 선택값을 몰래 수정하거나 지원한다고 주장하지 않는다. 예를 들어 C2.2에 XL이 있어도 데이터에 XL이 없으면 가능한 구성과 제한을 안내한다. C3.1의 +3도 같은 원칙이다.

G2.1의 “기존 주문에 합산”은 확정 전 현재 장바구니의 합계 갱신으로 지원한다. 확정 후에는 데이터 P06에 따라 같은 좌석의 새 주문을 만들고 과거 확정 내역을 보존한다. 확정 주문을 덮어쓰지 않는다.

F의 과업은 실제 돈을 처리하는 기능으로 확대하지 않는다. 시연 주문 확정과 실제 결제·접수 성공을 구분한다.

[55개 말단 과업의 구현·시험 대응표](HTI_상세_구현대응.csv)와 [67개 기존 질문의 박채원 HTI 대응표](../tests/fixtures/chaewon_case_map.csv)를 함께 사용한다. 번호가 세 단계인 세부 항목 53개와 자식 항목이 없는 C1·G1을 합친 말단 55개다.

기존 시험표의 hti_ids는 이전 원문의 번호이므로 현재 기준으로 읽지 않는다. 원문 시험표는 보존하고 새 대응표를 따로 두었다. 67개 질문이 모든 말단 과업과 입력 조합을 완전히 검증했다는 뜻은 아니다.
