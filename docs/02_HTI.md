# Hierarchical Task Inventory

브레인스토밍(Miro, KJ Method) → 9개 군집 → 과업 트리 순으로 정리했다.
**말단 과업 하나하나가 시연 시나리오이자 테스트 항목**이다.

## KJ 군집 9개 (오승재)

옵션 · 결제 · 다국어 · 매장이용 · 추천 · 테이크아웃 · 알레르기 · 진상 · 메뉴변경

## 과업 트리 (박채원 — 커피바 기준, 최종)

```
0. 커피바 좌석 태블릿으로 주문하기

A. 주문 시작하기
 A1. 대화 시작하기
  A1.1 주문 시작하기 [필수]
  A1.2 좌석 번호 확인하기 [필수]
 A2. 이용 환경 맞추기 [요청 시]
  A2.1 언어 바꾸기 (입력 언어 자동 감지 / 한·영·중·일)
  A2.2 화면 보기 편하게 바꾸기 (글자 크기, 고대비)
  A2.3 손쉬운 보기 기능 선택하기

B. 메뉴 탐색하기
 B1. 메뉴 찾기
  B1.1 카테고리로 둘러보기 (에스프레소·필터커피·논커피·디저트·원두)
  B1.2 메뉴 이름으로 묻기
 B2. 추천받기
  B2.1 취향으로 추천받기 (단맛·산미·고소함·바디감)
  B2.2 상황으로 추천받기 (첫 방문, 카페인 적게, 디저트와 함께)
  B2.3 시그니처·시즌 메뉴 소개받기 [제안]
 B3. 메뉴 정보 확인하기
  B3.1 기본 정보 (설명·가격·맛 노트) ← 메뉴 언급 시 기본 제공
  B3.2 원두 상세 (산지·가공·로스팅) [요청 시]
  B3.3 알레르기·성분 [요청 시]
  B3.4 카페인·칼로리 [요청 시]
 B4. 메뉴 비교하기
  B4.1 여러 메뉴의 맛·가격 비교하기

C. 메뉴 선택 및 옵션 정하기
 C1. 메뉴 고르기
 C2. 기본 옵션 정하기 [필수]
  C2.1 온도 (HOT / ICED)
  C2.2 사이즈 (S / L / ONE)
  C2.3 원두 (하우스 / 싱글오리진 / 디카페인) ← 커피 메뉴만
 C3. 맞춤 옵션 정하기 [요청 시]
  C3.1 샷 추가 (+1 / +2)
  C3.2 단맛 조절 (기본 / 절반)
  C3.3 우유 바꾸기 (일반 / 저지방 / 오트 / 두유)
  C3.4 얼음 조절
 C4. 옵션 확인하기
  C4.1 디저트 페어링 제안 수락·거절
  C4.2 사이즈 업·샷 추가 제안 수락·거절
  C4.3 적용된 옵션과 추가금 확인

D. 장바구니 관리하기
 D1. 담기 / D2. 수정하기(수량·옵션·빼기) / D3. 확인하기

E. 이용·수령 방식 정하기
 E1.1 매장 / 포장 선택 [필수]   ※ 주류는 매장 이용만 (P15)

F. 결제하기
 F2.1 최종 주문 내역 확인 [필수]
 F3.1 주문번호 확인
```
